# Номерки для 5D-кинотеатра

Программа печатает на термопринтере номерки с привязкой ко времени. Работает на одном ПК, без интернета, Docker и хостингов.

**Как это работает.** Оператор нажимает на фильм, и печатается номерок: номер (`A006`) и время, когда прийти (`18:30`).
Время считается по очереди: первый получает «сейчас», каждый следующий на N минут позже предыдущего.
Для 5D-кинотеатра N = 6 (5 минут сеанс + 1 минута запас): очередь с 18:00 даёт 18:00, 18:06, 18:12, … шестой — 18:30.

## Состав

| Роль | Пароль в `.env` | Что может |
|---|---|---|
| **Оператор** | `OPERATOR_PASSWORD` | начать и закончить смену, выдать номерок, напечатать его ещё раз |
| **Администратор** | `ADMIN_PASSWORD` | всё то же + вкладки «Фильмы», «История», «Настройки» |

Технически это один процесс Node.js (сервер + SQLite-база в файле) и веб-интерфейс на React, который открывается в браузере на этом же ПК.

## Установка на Windows

Делается **один раз** на рабочем ПК.

1. **Установите Node.js** версии 22.13 или новее: https://nodejs.org (скачайте LTS и нажимайте «Далее»).
2. **Скопируйте папку проекта** на ПК, например в `C:\Nomerki`. Путь лучше без пробелов.
   Папку нельзя потом перемещать: ярлыки запоминают путь. Если переместили, запустите установку заново.
3. Дважды щёлкните **`install-windows.bat`**.
   - Если файла `.env` ещё нет, откроется Блокнот. Поменяйте `ADMIN_PASSWORD` и `OPERATOR_PASSWORD` на свои, сохраните и закройте.
   - Дальше скрипт сам установит зависимости, соберёт интерфейс, создаст ярлык **«Номерки»** на рабочем столе и в автозагрузке и запустит программу.
   - Первая установка занимает 1–3 минуты (скачиваются пакеты, нужен интернет **только на этом шаге**).
4. Откроется окно программы. Войдите паролем администратора и выполните [первую настройку](#первая-настройка-администратор).

**Что происходит дальше каждый день.** Оператор включает ПК. Сервер стартует сам в фоне, и открывается окно «Номерки» (как отдельная программа, без адресной строки). Ничего вводить не нужно. Если окно закрыли, дважды щёлкните ярлык «Номерки» на рабочем столе.

**Служебные файлы:**

| Файл | Назначение |
|---|---|
| `install-windows.bat` | установка и создание ярлыков (можно запускать повторно) |
| `uninstall-windows.bat` | убрать ярлыки и автозапуск (данные не трогает) |
| `stop-windows.bat` | остановить сервер (например, перед обновлением) |
| `start.bat` | запустить вручную, с окном консоли (для отладки) |

## Установка на Ubuntu

1. Установите Node.js 22.13+ (https://nodejs.org или через `nvm`) и Chrome/Chromium.
2. Скопируйте папку проекта, например в `~/nomerki`.
3. В терминале:

```bash
cd ~/nomerki
./install-ubuntu.sh
```

Если `.env` нет, скрипт создаст его и попросит поменять пароли: откройте `.env`, отредактируйте и запустите скрипт ещё раз.
Скрипт соберёт проект и добавит запуск в автозагрузку (`~/.config/autostart/nomerki.desktop`).
Запустить сразу: `autostart/launch-ubuntu.sh`.

Принтер в Ubuntu ставится через «Параметры → Принтеры» (CUPS) и должен быть принтером по умолчанию.

## Ярлык вручную (если установщик не подошёл)

Ярлык запускает файл `autostart\launch.vbs`: он поднимает сервер в фоне (если не запущен) и открывает окно программы.

**Ярлык на рабочем столе:**
1. Правый клик на рабочем столе → Создать → Ярлык.
2. В поле расположения введите (подставьте свой путь):
   `wscript.exe "C:\Nomerki\autostart\launch.vbs"`
3. Назовите его «Номерки» → Готово.
4. (Необязательно) в свойствах ярлыка задайте «Рабочая папка» `C:\Nomerki`.

**Автозапуск при включении ПК:**
1. Нажмите `Win + R`, введите `shell:startup`, Enter. Откроется папка автозагрузки.
2. Скопируйте туда созданный ярлык.

**Убрать автозапуск:** удалите ярлык из `shell:startup` (или запустите `uninstall-windows.bat`).

**Запуск браузера вручную** (если пользуетесь не ярлыком, а своим Chrome), чтобы номерок печатался без диалога:

```
"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing --app=http://localhost:3000
```

Флаг `--kiosk-printing` действует, только если Chrome запущен «с нуля». Если Chrome уже открыт, закройте все его окна или добавьте `--user-data-dir="C:\Nomerki\data\browser-profile"`. Именно так делает `launch.vbs`.

## Первая настройка (администратор)

1. Войдите с паролем администратора.
2. **Вкладка «Фильмы».** По умолчанию уже создан один фильм «5D кинотеатр», буква `A`, **6 минут** на человека (5 мин сеанс + 1 мин запас). Изменить: «Изменить». Поля:
   - **Название** — печатается на номерке.
   - **Буква номерка** — `A`, `Б`, `5D` (до 3 символов). Номера: `A001`, `A002`…
   - **Минут на одного человека** — шаг между временами выдачи.
   - **Не раньше** (ЧЧ:ММ, необязательно) — если фильм начинается в 10:00, то раньше время не назначается.
   - **Запись до** (ЧЧ:ММ, необязательно) — после этого времени номерки на фильм не выдаются.
   - **Активен** — снимите галочку, чтобы скрыть фильм у оператора, не теряя историю.
3. **Вкладка «Настройки».** Укажите **папку для Excel-таблиц**: полный путь, например `D:\Номерки`. Если оставить пустым, файлы пойдут в `data\exports`. При сохранении программа проверяет, что в папку можно писать.
4. Запустите пробную смену и убедитесь, что номерок печатается (см. [Принтер](#термопринтер)). Пробную смену потом можно аннулировать во вкладке «История».

## Ежедневная работа оператора

1. Включить ПК. Окно «Номерки» откроется само. Войти паролем оператора.
2. Нажать **«Начать смену»**. Пока смена не открыта, кнопки фильмов неактивны.
3. Нажимать на кнопку фильма: номерок сразу печатается. На кнопке видно ближайшее свободное время и сколько человек в очереди. Если нужно перепечатать, кнопка «Печать ещё раз» в списке ниже.
4. В конце смены нажать **«Закончить смену»**. Программа:
   - закроет смену и сохранит **Excel-таблицу** в папку из настроек (покажет зелёное сообщение с путём);
   - сделает копию базы данных;
   - следующая смена начнётся с нуля (нумерация `A001…` и очередь заново).
5. Выключить ПК можно в любой момент: данные уже сохранены. Если смену забыли закрыть, она останется открытой до следующего дня. Просто закройте её и начните новую.

Если запись на фильм закончилась (прошло время «Запись до»), кнопка станет неактивной с надписью «Запись закончена».

## Термопринтер

Печатает браузер через обычный драйвер принтера, никаких специальных программ не нужно.

1. **Установите принтер** в системе драйвером производителя, сделайте его **принтером по умолчанию** (Windows: Параметры → Принтеры и сканеры).
2. **Размер номерка** задаётся в `client\src\theme.css`, блок `--ticket-*`:
   - `--ticket-width: 58mm;` — ширина ленты (`58mm` или `80mm`);
   - `--ticket-height: 80mm;` — высота листа; подберите так, чтобы не уходило лишней бумаги;
   - размеры шрифтов номера, времени и подписей.
   После правки выполните сборку: `npm run build` (или удалите папку `client\dist` и запустите `install-windows.bat`).
3. **В драйвере принтера** (Свойства принтера → Настройка печати) выберите ширину бумаги, как у вашей ленты, и поля 0, если есть такая настройка.
4. **Тихая печать.** Ярлык «Номерки» открывает Chrome с `--kiosk-printing`, поэтому диалог печати не появляется. Если открыть сайт обычным браузером, появится стандартное окно печати: нажмите «Печать».
5. Подпись внизу номерка: `TICKET_FOOTER` в `.env`. Название заведения вверху: `BRAND_NAME`.

## Данные, смены, Excel, копии

Всё лежит в папке **`data`** рядом с программой:

| Что | Где |
|---|---|
| База со всеми фильмами, сменами, номерками | `data\tickets.db` |
| Автокопии базы (последние 30) | `data\backups\` — создаются при закрытии смены |
| Excel-таблицы по умолчанию | `data\exports\` (или папка из «Настроек») |
| Журнал сервера (для диагностики) | `data\server.log` |

**Excel-таблица смены.** Название файла — дата дня, например `2026-11-10.xlsx`. Если смен за день несколько, дальше `2026-11-10 (2).xlsx` и т. д. (ничего не перезаписывается). Два листа:
- «Номерки»: порядковый номер, номерок, фильм, во сколько выдан, на какое время приглашён, статус;
- «Итого»: смена, когда открыта и закрыта, количество по фильмам и всего.

Если папка для Excel недоступна (например, вынута флешка), смена всё равно закроется, а оператор увидит красное сообщение. Таблицу можно скачать позже: «История» → кнопка **«Excel»** у нужной смены.

**История** (админ): список всех смен, развернуть номерки, аннулировать ошибочный номерок, скачать Excel смены, скачать копию базы.

**Файл `.env` и папка `data`** не входят в git (`.gitignore`): пароли и данные не попадут в репозиторий.

## Внешний вид

Все цвета, шрифты, радиусы, размеры кнопок фильмов и размеры номерка вынесены в переменные в **`client\src\theme.css`**, блок `:root`. Менять нужно только значения, например:

```css
--color-primary: #7c5cff;   /* главный цвет кнопок и акцентов */
--color-bg: #0f1420;        /* фон */
--font-family: 'Segoe UI', system-ui, sans-serif;
```

После правки пересоберите интерфейс: `npm run build` в папке проекта и перезапустите ярлык (`stop-windows.bat`, потом двойной клик по «Номерки»).

## Обновление и перенос на другой ПК

**Перенос на другой ПК:**
1. На новом ПК установите Node.js и скопируйте папку проекта целиком (включая `.env` и `data`, если нужны старые данные).
2. Запустите `install-windows.bat`.

**Обновление программы:** запустите `stop-windows.bat`, замените файлы проекта (папки `data` и файл `.env` не трогайте), запустите `install-windows.bat`.

**Резервная копия:** достаточно периодически копировать папку `data` в безопасное место.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| Окно открылось, но «Failed to fetch» / страница не грузится | Сервер не запущен. Дважды щёлкните ярлык «Номерки», он поднимет сервер. Причина — в `data\server.log` |
| При запуске ошибка «Server did not start» | Откройте `data\server.log`. Частые причины: порт занят другой программой (смените `PORT` в `.env`), не установлен Node.js |
| Не входит, «Неверный пароль» | Пароли в файле `.env` (`ADMIN_PASSWORD`, `OPERATOR_PASSWORD`). После правки `.env` перезапустите сервер (`stop-windows.bat`, ярлык). После 8 неверных попыток вход блокируется на 5 минут |
| Нельзя выдать номерок | Не начата смена («Начать смену») или у фильма закончилась запись (поле «Запись до») |
| Печатается окно диалога | Окно открыто не ярлыком. Закройте и запустите ярлык «Номерки» (флаг `--kiosk-printing`) |
| Печатается не тот размер / лишняя бумага | Настройте `--ticket-width` и `--ticket-height` в `theme.css` и размер бумаги в драйвере принтера |
| Excel не сохраняется | Проверьте папку во вкладке «Настройки». Файл всегда можно скачать из «Истории» |
| Время на номерке неверное | Проверьте дату, время и часовой пояс в самой системе |
| Нужно открыть с другого устройства в сети | В `.env` поставьте `HOST=0.0.0.0`, перезапустите, откройте `http://IP-этого-ПК:3000` (в брандмауэре разрешите порт). Печатать при этом будет то устройство, с которого открыли |

## Настройки в `.env`

| Параметр | Значение |
|---|---|
| `PORT` | порт программы (по умолчанию 3000) |
| `HOST` | `127.0.0.1` — только этот ПК (рекомендуется); `0.0.0.0` — доступ по сети |
| `ADMIN_PASSWORD`, `OPERATOR_PASSWORD` | пароли ролей |
| `SESSION_SECRET` | длинная случайная строка для подписи входа (не меняйте без необходимости) |
| `SESSION_HOURS` | сколько часов держится вход (12) |
| `BRAND_NAME` | название вверху номерка и в шапке |
| `TICKET_FOOTER` | подпись внизу номерка |
| `LOCALE` | формат даты (`ru-RU`) |
| `EXPORT_DIR` | папка для Excel по умолчанию (её можно задать и в «Настройках») |
| `TZ` | часовой пояс, если нужно задать явно (на Windows обычно не нужен) |

Образец: `.env.example`. Пароли храните только в `.env`, в код и репозиторий они не попадают.

## Для разработчика

```text
server/            Express + SQLite (node:sqlite), смены, очередь, Excel (exceljs)
  index.js           маршруты API и раздача интерфейса
  queue.js           смены и расчёт времени номерка
  export.js          Excel-таблицы и папка экспорта
  auth.js, db.js     вход по ролям, база
client/            React + Vite
  src/theme.css      ВСЕ цвета и размеры (редактируется пользователем)
  src/app.css        стили, использующие переменные
  src/Ticket.jsx     макет печатаемого номерка
autostart/         запуск без консоли (launch.vbs, установка ярлыков)
```

Разработка:

```bash
npm run setup         # установка зависимостей server и client
npm run dev:server    # бэкенд на :3000
npm run dev:client    # интерфейс с горячей перезагрузкой на :5173
npm run build         # сборка интерфейса в client/dist
npm start             # запуск без автозапуска (нужен собранный client/dist)
```

Требуется Node.js 22.13+ (используется встроенный `node:sqlite`, он выводит предупреждение «experimental» — это нормально).
